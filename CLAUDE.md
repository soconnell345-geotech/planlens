# planlens

PDF / drawing document layer for LLM-assisted review of AEC documents
(`planlens.document`, `planlens.ir`, `planlens.tools`, `planlens.pdf`). Its main
consumer is the GeotechStaffEngineer app (`../GeotechStaffEngineer`), which pins
a released planlens version from PyPI.

## Open work lives in ONE list

All open work for planlens is in **`BACKLOG.md` in the GeotechStaffEngineer
repo**, §5 (PL-nn), with planlens items under other areas too, such as VIS and
DOC. That file is the one list across the app, planlens and geotech-references
(owner's rule, 2026-10-12).
- **New to-dos:** add them there with the next free ID.
- **Do not start a to-do list here:** not in this repo's README, CHANGELOG or design notes.
- **"Not built yet" and "open list" sections** in `planlens/*/DESIGN.md` are detail; the backlog line points at them.

## Working here

- **Tests:** `pytest planlens -q` (planlens' own suite). Gate on pytest's exit code, not on piped output.
- **Releases:** owner-gated. A `v*` tag publishes to PyPI. planlens is published BEFORE an app release that raises the pin.
- **Published numbers:** every corpus figure in the docs is regenerated by `../GeotechStaffEngineer/module_work/drawing_ground_truth/doc_claims_check.py`. If a number disagrees with it, fix the document.
- **The repo is PUBLIC.** No Department material, client names, hostnames or emails.
