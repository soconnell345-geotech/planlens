# planlens

PDF / drawing document layer for LLM-assisted review of AEC documents
(`planlens.document`, `planlens.ir`, `planlens.tools`, `planlens.review`,
`planlens.pdf`). Its consumers are in the GeotechStaffEngineer repo
(`../GeotechStaffEngineer`), all on PyPI: the shared core `aec-agent-core`
(`packages/aec-agent-core`; it binds `planlens.review` to the agents), the
GeotechStaffEngineer app, and Document Review (`aec-document-review`,
`packages/aec-document-review`). Each requires a released planlens version
(Document Review pins it exactly).

## Working here

- **Tests:** `pytest planlens -q` (planlens' own suite). Gate on pytest's exit code, not on piped output.
- **Releases:** owner-gated. A `v*` tag publishes to PyPI. planlens is published BEFORE any release that raises a pin on it (the core, the app or Document Review).
- **Published numbers:** every corpus figure in the docs is regenerated by `../GeotechStaffEngineer/module_work/drawing_ground_truth/doc_claims_check.py`. If a number disagrees with it, fix the document.
- **The repo is PUBLIC.** No Department material, client names, hostnames or emails.
